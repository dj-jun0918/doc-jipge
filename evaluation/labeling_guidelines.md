# Ground Truth 라벨링 가이드라인

**작성**: 임태규 (초안) / 방정우 (보강 예정)  
**버전**: v0.1 (PR#3)  
**목적**: 30개 GT 라벨링 기준 통일 — ann_001~030 전체 일관성 확보

---

## 1. 파일 구조
evaluation/ground_truth/ann_NNN/
└── ground_truth.json

### ground_truth.json 필드 명세

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `announcement_id` | string | ✅ | `"ann_001"` 형식 |
| `title` | string | ✅ | 공고 원문 제목 그대로 |
| `source_url` | string | ✅ | 공고 원문 URL |
| `fields` | array | ✅ | 자격요건 필드 목록 |
| `exclusions` | array | ✅ | 신청제외 조건 목록 (없으면 `[]`) |
| `notes` | string | ❌ | 라벨러 판단 메모, 모호한 조건 설명 |

---

## 2. 필드별 라벨링 기준 (7개 필드)

### 2-1. 업력

- `field_name`: `"업력"`
- `condition`: 공고 원문 표현 그대로 기재
  - 예: `"3년 미만"`, `"7년 이하"`, `"6개월 이상"`, `"1년 이상 7년 이하"`
- `evidence`: 조건이 명시된 원문 문장 그대로 인용
- `evidence_source`: 페이지 및 항목 위치 명시

**operator 매핑 기준**

| 원문 표현 | operator |
|-----------|----------|
| N년 미만 | `"미만"` |
| N년 이하 | `"이하"` |
| N년 이상 | `"이상"` |
| N년 초과 | `"초과"` |
| N년 이상 M년 이하/미만 | `"범위"` |

> ⚠️ "미만"과 "이하" 엄격 구분. "창업 후 3년" 표현은 문맥상 "이하" 또는 "미만" 판단하여 `notes`에 근거 기재.

---

### 2-2. 지역

- `field_name`: `"지역"`
- `condition`: 정규화된 지역명 사용 (REGION_GROUPS 기준)
  - 예: `"서울"`, `"경기"`, `"강원"`, `"전국"`
  - 시·군·구 단위 조건은 원문 그대로 기재 (예: `"광명시"`, `"춘천시"`)
- `operator`: `"소재"` (일반적), `"무관"` (전국 조건)

**전국 조건 처리**
- "전국 소재", "제한 없음", "지역 무관" → `condition: "전국"`, `operator: "무관"`

---

### 2-3. 매출

- `field_name`: `"매출"` (일부 공고는 `"매출액"` — 원문 표현 따름)
- `condition`: 원문 그대로 기재
  - 예: `"2억원 이상"`, `"10억원 미만"`, `"1억원 이상 50억원 미만"`
- 기준 연도가 명시된 경우 그대로 포함
  - 예: `"직전년도(2025) 또는 최근 3개년 연매출 2억원 이상"`

---

### 2-4. 종업원 수

- `field_name`: `"종업원 수"`
- `condition`: 원문 그대로 기재
  - 예: `"5인 미만"`, `"10인 이상 300인 미만"`
- 업종별로 기준이 다른 경우: 업종 구분 포함하여 기재
  - 예: `"광업·제조·건설·운수업 10인 미만 / 그 외 업종 5인 미만"`

---

### 2-5. 나이

- `field_name`: `"나이"`
- `condition`: 원문 그대로 기재
  - 예: `"만 39세 이하"`, `"만 60세 이상"`
- "만 나이" 표현 필수 확인 — "만" 없는 경우 `notes`에 명기

---

### 2-6. 업종

- `field_name`: `"업종"`
- `condition`: 허용/제외 업종 원문 기재
  - 예: `"제조업"`, `"소상공인 정책자금 지원제외 업종 외"`
- `operator`: `"포함"` (허용 업종 나열), `"제외"` (금지 업종 나열)
- 업종 목록이 긴 경우: 대표 업종 + "등" 으로 요약 가능, `notes`에 전체 목록 출처 기재

---

### 2-7. 인증

- `field_name`: `"인증"`
- `condition`: 요구 인증명 원문 기재
  - 예: `"벤처기업 인증 보유"`, `"이노비즈 인증 보유"`
- `operator`: `"보유"` (인증 있어야 함), `"미보유"` (인증 없어야 함)

---

## 3. condition 작성 규칙

### 원문 그대로 vs 정규화

| 케이스 | 규칙 | 예시 |
|--------|------|------|
| 수치 조건 | 원문 그대로 | `"3년 미만"`, `"2억원 이상"` |
| 지역명 | REGION_GROUPS 정규화 | `"서울특별시"` → `"서울"` |
| 시·군·구 | 원문 그대로 | `"광명시"`, `"춘천시"` |
| 복합 조건 | 원문 그대로, `/` 로 구분 | `"10인 미만 / 5인 미만"` |
| 인증명 | 원문 그대로 | `"벤처기업 인증 보유"` |

---

## 4. operator 후보 목록

| operator | 적용 필드 | 설명 |
|----------|-----------|------|
| `"미만"` | 업력, 매출, 종업원 수, 나이 | 미만 (경계값 미포함) |
| `"이하"` | 업력, 매출, 종업원 수, 나이 | 이하 (경계값 포함) |
| `"이상"` | 업력, 매출, 종업원 수, 나이 | 이상 (경계값 포함) |
| `"초과"` | 업력, 매출, 종업원 수, 나이 | 초과 (경계값 미포함) |
| `"범위"` | 업력, 매출, 종업원 수, 나이 | N 이상 M 이하/미만 |
| `"소재"` | 지역 | 특정 지역 소재 |
| `"무관"` | 지역 | 전국, 지역 제한 없음 |
| `"포함"` | 업종 | 허용 업종 목록 |
| `"제외"` | 업종 | 금지 업종 목록 |
| `"보유"` | 인증 | 인증 보유 필수 |
| `"미보유"` | 인증 | 인증 없어야 함 |

---

## 5. confidence 사용 기준

현재 ground_truth.json 스키마에 `confidence` 필드는 없으나, 모호한 케이스는 `notes`에 명기.

**`notes`에 기재해야 할 케이스**

- 조건이 본문이 아닌 첨부파일·별표에만 있는 경우
- "창업 후 N년" 표현이 미만/이하 중 어느 것인지 불명확한 경우
- 업종 조건이 포함/제외 목록이 혼재된 경우
- 수치 조건의 기준일(공고일/접수일/신청일)이 불명확한 경우
- 복수 조건이 AND인지 OR인지 불명확한 경우

---

## 6. exclusions 작성 규칙

- 원문 문장 그대로 기재 (요약 금지)
- `[cite: N]` 출처 표기는 선택사항 (ann_001 스타일)
- 일반적인 공통 제외 조건 (체납, 휴폐업, 채무불이행)은 반드시 포함
- 업종 제외 조건이 있으면 별도 항목으로 분리

---

## 7. 라벨링 체크리스트 (개인 검수)

- [ ] `title`이 공고 원문 제목과 일치하는가
- [ ] `source_url`이 실제 접근 가능한 URL인가
- [ ] 모든 수치 조건에 operator가 명확히 매핑되는가
- [ ] "미만"/"이하", "이상"/"초과" 혼동 없는가
- [ ] 지역명이 REGION_GROUPS 기준으로 정규화되었는가
- [ ] exclusions에 휴폐업/체납/채무불이행 포함되었는가
- [ ] 모호한 조건은 `notes`에 근거가 기재되었는가
- [ ] JSON 문법 오류 없는가 (`python -m json.tool`로 검증)
